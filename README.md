# 🌦️ WeatherPulse - Full Stack Weather Application

A modern, responsive real-time weather forecasting web application built with React, Node.js, Express, and OpenWeatherMap API.

## 🚀 Live Demo Links
* **Render (Primary):** https://ibm-fullstack-mini-project.onrender.com
* **Vercel (Mirror):** https://ibm-fullstack-mini-project.vercel.app

## 🛠️ Tech Stack
* **Frontend:** React.js, CSS3 (Glassmorphism)
* **Backend:** Node.js, Express.js
* **API:** OpenWeatherMap REST API
* **Deployment:** Render, Vercel
